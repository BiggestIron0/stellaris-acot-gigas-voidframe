Load order files for the Steam Workshop collection

## How to use

1. Subscribe to all mods in the collection and let Steam finish downloading.
2. Open [Irony Mod Manager](https://github.com/bcssov/IronyModManager).
3. Collection dropdown → **Import** → pick `ACOT+GIGAS+VOIDFRAME.zip` from this repo
   ([direct download](../../raw/main/ACOT%2BGIGAS%2BVOIDFRAME.zip)).
4. Verify the order matches [`load-order.txt`](load-order.txt), then **Apply**.

Questions/comments → the collection's Steam page.
